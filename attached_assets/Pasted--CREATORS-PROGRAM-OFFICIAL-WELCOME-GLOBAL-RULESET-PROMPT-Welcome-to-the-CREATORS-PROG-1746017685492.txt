**GLOBAL RULES – DO NOT BREAK**

1. **Single-Language Enforcement:**
   - Your platform must remain entirely in **one language** only.
   - If you started in English, continue in English. If Spanish, stay in Spanish.
   - No mixed-language content.

2. **Style Lock:**
   - You are strictly forbidden from changing any **font, color, button style, layout, or text size**.
   - All approved designs have already passed a visual inspection.
   - No dark mode/light mode toggles unless pre-approved.

3. **No Custom Modifications Allowed:**
   - Do not add, rename, delete, or move any UI components, tabs, or subtabs.
   - Do not alter the base structure or logic without explicit instruction.

4. **All APIs Must Be Live:**
   - Firebase Auth must be connected.
   - Vertex AI (Gemini 1.5 / 2.5 Pro) must be working.
   - Google Cloud (TTS, STT, Translate, Docs) must be authenticated.
   - Stripe or payment APIs must be loaded if included in the app.

5. **Master Structure Validation Required:**
   - You must run a full internal structure check (see below).
   - Report what tabs exist, what features are working, and what integrations are live.
   - Create a **full app map** showing the exact status of each component.

6. **Prompt History Must Be Preserved:**
   - Do not delete or override previous prompts or instructions.
   - Any generation must begin by referencing your original prompt and using it as context.

7. **No AI Style Drift Allowed:**
   - Gemini/Vertex must not infer, alter, or reinterpret brand styles.
   - Maintain the tone, personality, and purpose of the platform exactly as defined.

8. **Global Agent Sync:**
   - If your platform supports another app (Avatar, CRM, Booking), it must communicate correctly.
   - Do not duplicate support modules unless instructed.

9. **Versioning:**
   - Any update must be timestamped and versioned (v1.0.0, v1.0.1, etc.)
   - Use changelogs to track new functionality added to each release.

10. **No Deployment Without Final Checkpoint Approval:**
    - All 20 checkpoints below must pass before deploying or publishing your platform.

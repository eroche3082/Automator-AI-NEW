**MEGAPROMPT – ALL-IN-ONE AUTOMATION SYSTEM (AUTOMATOR AI)**

**Nombre:** AUTOMATOR AI (Sistema de Automatización Total)
**Propósito:** Plataforma centralizada para automatizar procesos de negocios, gestión de tareas, seguimiento de leads, envío de correos, flujos operativos y conexión con servicios externos.

Ideal para vender como SaaS a empresas, agencias, freelancers y equipos de ventas que buscan optimizar tiempo y escalar sin contratar más personal.

---

**TECNOLOGÍA BASE:**
- **Frontend:** React + Tailwind + ShadCN/UI
- **Backend:** Node.js + Express
- **Base de Datos:** PostgreSQL + Firebase
- **AI:** Vertex AI 2.5 Pro + Gemini 1.5 Flash
- **Integraciones activas:**
  - Google Calendar, Gmail, Google Sheets, Google Docs
  - Discord, Notion, Trello, Zapier, Webhooks
  - Stripe, Calendly, CRMs (Hubspot, Zoho)
  - WhatsApp API, Email SMTP, Cloud Scheduler
- **Deployment:** Firebase Hosting + Replit Dev

---

**DASHBOARD ESTRUCTURAL (6 TABS)**

1. **Home – Automation Hub**
   - Bienvenida personalizada por IA
   - Actividad reciente + tareas automatizadas activas
   - KPIs clave: procesos, tiempo ahorrado, resultados

2. **Workflows & Triggers**
   - **Subtabs:**
     - Crear flujo automático (IF/THEN/ELSE)
     - Acciones por API (ej. “Enviar Gmail si se completa formulario”)
     - Webhooks personalizados
     - Acciones programadas por hora, día, evento
     - Plantillas de automatización por industria

3. **CRM & Lead Automation**
   - **Subtabs:**
     - Base de datos de clientes / leads
     - Seguimiento automático de intención (mensajes, apertura, clics)
     - Flujo de onboarding (correo + Docs + Calendly)
     - Clasificación por tags inteligentes
     - Notificaciones vía email / WhatsApp / Discord

4. **Email & Document Automation**
   - **Subtabs:**
     - Redacción de correos inteligentes con AI
     - Secuencia de correos activados por eventos
     - Conexión con Google Docs (contratos, propuestas, reportes)
     - Generación automática de PDFs y Docs con IA
     - Firma electrónica e integración con DocuSign

5. **Calendars & Scheduling**
   - **Subtabs:**
     - Integración con Google Calendar y Calendly
     - Agenda inteligente por disponibilidad
     - Envío automático de invitaciones y recordatorios
     - Gestión de múltiples calendarios por proyecto
     - Historial de reuniones + tareas asignadas

6. **Settings & API Manager**
   - Activar/desactivar integraciones por cliente o equipo
   - Conectar cuentas (Google, Stripe, Zapier, Discord, etc.)
   - Clave API por usuario
   - Notificaciones, idioma, seguridad y backups

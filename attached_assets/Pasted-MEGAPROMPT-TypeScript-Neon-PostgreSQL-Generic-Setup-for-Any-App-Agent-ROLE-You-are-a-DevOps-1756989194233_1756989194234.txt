MEGAPROMPT — TypeScript + Neon (PostgreSQL) — Generic Setup for Any App/Agent

ROLE
You are a DevOps + Full-Stack Agent. Your mission is to connect this project to a Neon PostgreSQL database using TypeScript, validate connectivity, and keep the codebase ORM-ready (Prisma/Drizzle compatible).

INPUTS (replace as needed)

DATABASE_URL = postgresql://<user>:<pass>@<host>/<db>?sslmode=require (Neon connection string)

App root uses Node.js + TypeScript (or install it below)

OBJECTIVES

Install all PostgreSQL dependencies for TypeScript.

Configure .env (or Replit Secrets) with DATABASE_URL.

Create src/lib/db.ts with a production-safe Neon connection.

Verify the database connection via src/testConnection.ts.

Keep compatibility for future Prisma/Drizzle integration.

⚙️ EXECUTION — STEP BY STEP
🔹 1) Install dependencies
npm install pg
npm install -D typescript ts-node @types/node @types/pg


If TypeScript isn’t initialized yet:

npx tsc --init


(Optional but recommended in package.json)

{
  "engines": { "node": "20" },
  "scripts": {
    "db:test": "ts-node src/testConnection.ts"
  }
}

🔹 2) Configure environment variable

Set DATABASE_URL in Replit Secrets or a local .env:

DATABASE_URL=postgresql://<user>:<pass>@<host>/<db>?sslmode=require


Never commit real credentials. Use Secrets in CI/CD too.

🔹 3) Create the connection file db.ts

Location: src/lib/db.ts

import { Pool } from 'pg';

const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
  // Neon requires SSL; this setting keeps TS/Node happy in serverless envs
  ssl: { rejectUnauthorized: false },
});

export default pool;

🔹 4) Create a test script to validate connectivity

File: src/testConnection.ts

import pool from './lib/db';

async function main() {
  try {
    const result = await pool.query('SELECT NOW() AS now');
    console.log('✅ Connected to Neon. Server time:', result.rows[0].now);
  } catch (err) {
    console.error('❌ Neon connection error:', err);
    process.exitCode = 1;
  } finally {
    await pool.end();
  }
}

main();


Run:

npx ts-node src/testConnection.ts


Expected output (example):
✅ Connected to Neon. Server time: 2025-08-31T08:12:00Z
